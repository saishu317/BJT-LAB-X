FORMULA REFERENCES

Base Current
\( I_B = \dfrac{V_{SENSOR} - V_{BE}}{R_B} \)
Current flowing into the transistor base
Collector Current
\( I_C = \beta \times I_B \)
Current flowing through the collector-emitter path
Saturation Current
\( I_{C(sat)} \approx \dfrac{V_{CC} - V_{CE(sat)}}{R_L} \)
Maximum collector current in saturation (~98.3 mA)
Power Dissipation
\( P_D = V_{CE} \times I_C \)
Power converted to heat in the transistor

EXACT CRITERIA FOR BJT OPERATING REGIONS

SATURATION REGION (VCE ≤ 0.40 V)
Boundary: VCE ≤ 0.40 V, RB ≤ 2.15 kΩ (PS-37 Deep Saturation: VCE ≤ 0.20 V at RB = 1.3 kΩ).
Junction State: Both E-B and C-B junctions are forward-biased.
Device Behavior: Acts as a closed switch (RON ≈ 2 Ω). Collector current is clamped by the load to maximum (~97–100 mA).
Buzzer Output: FULLY ACTIVE (ON ⚡).
ACTIVE REGION (0.40 V < VCE < 11.5 V)
Boundary: 0.40 V < VCE < 11.5 V, 2.15 kΩ < RB < 50 kΩ.
Junction State: E-B junction forward-biased, C-B junction reverse-biased.
Device Behavior: Operates as a linear current amplifier (IC = β·IB). Collector current is proportional to base drive.
Buzzer Output: INACTIVE (OFF ⭕) — Current is below the rated 100 mA buzzer threshold.
CUT-OFF REGION (VCE ≥ 11.5 V)
Boundary: VCE ≥ 11.5 V, RB ≥ 50 kΩ or Sensor Signal = 0 V.
Junction State: Both junctions are reverse-biased.
Device Behavior: Acts as an open switch. Base current IB ≈ 0, collector leakage IC ≈ 0, and VCE ≈ VCC (12 V).
Buzzer Output: INACTIVE (OFF ⭕).
